# Weekly Participation Admin Snapshot

This workflow publishes a read-only, provisional Participation Steward snapshot
to the Participation module once per ISO week. It never creates a DAO proposal,
issues shares, changes subscriptions, or changes entitlements.

The current Hall Monitor Participation Steward model is authoritative:

- Engagement: 20
- Stewardship: 60
- Contribution: 70
- Maximum: 150 per cycle

Use the current Hall Monitor source export and cite supporting Prism evidence.
Resolve identity by Gnosis wallet. Discord handles and display names are labels,
not identity keys. Missing or ambiguous evidence must become an audit flag rather
than a guessed score.
